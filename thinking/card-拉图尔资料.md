## 二、核心思想

### 1. 行动者网络理论（ANT）

与米歇尔·卡龙、约翰·劳共同创立。核心主张：

- **广义对称性**：人类与非人类（技术、设备、微生物、观念）应被同等对待，都是"行动者"（actant）
- **转译**：行动者之间的连接通过转译完成——不断改变、转述、转化彼此的利益和意图
- **网络**：不是社会网络，而是"行动的过程"——联结的动态过程
- **准客体**：打破自然/社会二元对立，提出主客体混合体

> "这本书最初是对科学的批判，但如今却已被科学家用来帮助开展研究。"——2015 年《实验室生活》再版

### 2. "我们从未现代过"

拉图尔最著名的命题：

- **现代性的核心神话**：存在一个根本性的"净化"——自然（客观事实）与社会（主体文化）的严格分离
- **实际状况**：生活中充满了"杂合物"——全球变暖、臭氧空洞、转基因生物——它们同时是自然、社会、政治和科学的
- **结论**：现代性从未真实存在过，我们一直是"非现代"的
- 他不是后现代主义者，而是**非现代主义者**（amodernist 或 nonmodernist）

### 3. 科学的人类学研究

- 把科学当作一种"文化"来做民族志研究
- 科学事实不是被"发现"的，而是在社会-物质网络中"建造"的
- 科学家的核心工作：被说服和说服他人

### 4. 生态转向

晚年聚焦于人类世（Anthropocene）和气候危机：

- **"陆地"（Terrestrial）**：提出一个新政治主体——以地球表面薄薄的生物圈为中心
- 人类无法从远处观察自然，因为我们嵌在其中
- 呼吁政治体系从现代性的左/右轴转向全球化 vs 陆地的轴

## 四、争议与自我批判

### 极端的建构论？
- 拉图尔曾说："在科赫 1882 年发现结核杆菌之前，不能说结核杆菌已经存在。拉美西斯二世不可能是死于结核病的。"
- 哲学家约翰·塞尔（John Searle）批评这是"有严重缺陷的"立场

### "批判已经耗尽"（2004 年著名自我批判）
- 拉图尔担心自己开创的科学论工具被气候变化否认者和阴谋论者挪用
- 提出从"事实"（matter of fact）转向"关切"（matter of concern）
- 这是他对自身学术遗产的一次坦诚反思

## 六、关键词速查

| 关键词 | 一句话 |
|--------|--------|
| 行动者网络理论（ANT） | 人类和非人类同等作为行动者，构成动态网络 |
| 广义对称性 | 不预设自然/社会孰先孰后，同时进入解释框架 |
| 转译（Translation） | 行动者之间不断改变、转述、转化彼此 |
| 准客体（Quasi-object） | 既是自然也是社会的混合体——如臭氧洞、全球变暖 |
| 我们从未现代过 | 现代性的自然/社会二分从未真实存在 |
| 非现代（Nonmodern） | 既非前现代、也非后现代，而是第三种立场 |
| 不变的可动者 | 能让远方事物"来到眼前"的视觉化工具——地图、图表、标本 |
| 关切（Matter of concern） | 取代"事实"——科学对象应被当作引发集体关切的议题 |
| 陆地（Terrestrial） | 人类世的新政治主体，取代左/右轴 |
| 盖娅 | 洛夫洛克的盖娅假说被转化为政治-哲学概念 |
