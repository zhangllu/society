# 近代西方社会的两次大革命

## 一、产业革命（英国，约 1760–1840）

### 时间线

| 时期 | 关键事件 |
|------|---------|
| 1760s–1780s | 纺织机械革命（珍妮纺纱机、水力纺纱机） |
| 1780s–1800s | 瓦特改良蒸汽机，工厂制度确立 |
| 1800s–1840s | 交通革命（铁路、蒸汽船），机器制造业成熟 |

### 核心突破

- **动力革命**：瓦特蒸汽机使工厂摆脱水力依赖，只要有煤就能运行（1800 年英国 321 台 → 1825 年 15000 台）
- **交通革命**：1825 年第一条客运铁路通车，运河网达 2200 英里
- **铁产量**：1720 年不到 2 万吨 → 1839 年 134.7 万吨
- **完成标志**：19 世纪 30–40 年代"用机器制造机器"的机器制造业诞生

### 社会后果

- **阶级结构**：工业资产阶级 vs 工业无产阶级两大阶级形成
- **城市化**：人口向伯明翰-利物浦-赫尔三角地带转移，工业城市崛起
- **劳动状况**：工人每天 12–16 小时，大量使用童工女工，居住贫民窟
- **反抗运动**：卢德捣毁机器 → 工会组织 → 宪章运动
- **思想产物**：自由主义（亚当·斯密《国富论》）、社会主义、马克思主义

## 二、法国大革命（1789–1799）

### 革命背景

- **经济危机**：支持美国独立战争导致国库空虚；1787–1788 年农业歉收引发严重饥荒，面包价格暴涨
- **阶级矛盾**：三个等级制度——教士（第一）、贵族（第二）与平民（第三），前两个等级享有特权，第三等级承担全部税负
- **启蒙思想**：伏尔泰、卢梭、孟德斯鸠提出"主权在民""自由、平等、博爱"

### 关键节点

| 时间 | 事件 |
|------|------|
| 1789.5 | 三级会议召开（中断 175 年后重启） |
| 1789.6.20 | 网球场宣言："不制定出宪法决不解散" |
| **1789.7.14** | **攻占巴士底狱**——革命爆发标志 |
| 1789.8.26 | 《人权宣言》："人生而自由，权利平等" |
| 1792 | 法兰西第一共和国成立，路易十六被处死 |
| 1793–1794 | 雅各宾派专政（恐怖统治） |
| 1794.7 | 热月政变 |
| 1799 | 拿破仑雾月政变 |

### 革命摧毁了什么

- **封建制度**：取消贵族教士特权，废除封建地租和什一税
- **等级制**：三个等级的旧秩序被打破
- **专制王权**："主权在民"替代"君权神授"

### 革命确立了什么

- 法律面前人人平等、私有财产不可侵犯
- 代议制政府、主权在民原则
- "自由、平等、博爱"成为现代政治基本理念
- 公制度量衡、统一税收、行政区划改革

## 三、两者对近代社会学的意义

这两大革命对当时的思想家构成了核心问题意识，直接催生了社会学这门学科：

| 思想家 | 面对的核心问题 |
|--------|-------------|
| **孔德**（社会学之父） | 大革命后的社会动荡 → 如何重建社会秩序？→ 提出"进步与秩序" |
| **马克思** | 产业革命创造的工人阶级苦难 + 资产阶级革命的政治承诺落空 → 批判资本主义，提出历史唯物主义 |
| **涂尔干** | 工业革命导致传统社会纽带瓦解 → 如何实现新的社会团结？→ 《社会分工论》 |
| **韦伯** | 资本主义如何兴起？理性化如何"铁笼般"束缚现代人？→ 《新教伦理与资本主义精神》 |
