# 布鲁诺·拉图尔：最小全局

## 1. 人物生平：他的一生大致如何展开

布鲁诺·拉图尔（Bruno Latour，1947—2022）出生于法国勃艮第地区，受哲学与神学训练，后来进入科学技术研究领域。他的研究对象不断变化，但始终围绕一个问题：知识、事实和秩序是如何在具体实践中形成的。

### 生平线索

```text
哲学／神学训练
→ 科特迪瓦经历与人类学兴趣
→ 索尔克研究所的实验室田野
→ 科学技术研究与行动者网络理论
→ 现代性批判
→ 盖娅与气候政治
```

### 关键节点

| 时期 | 经历与工作 | 思想线索 |
|---|---|---|
| 1947—1970s | 出生、求学，接受哲学与神学训练 | 对信仰、知识和解释方式的兴趣 |
| 1970s | 在科特迪瓦经历工作，接触人类学和跨文化研究 | 从现场和实践理解知识 |
| 1976—1977 | 在美国索尔克研究所进行实验室研究 | 科学事实如何在实验室中形成 |
| 1979 | 与史蒂夫·伍尔加合著《实验室生活》 | 科学民族志与事实建构研究 |
| 1980s—1990s | 发展科学技术研究，与卡龙、约翰·劳等合作 | 行动者、网络、转译和黑箱 |
| 1990s—2000s | 讨论现代性及自然／社会二分 | 《我们从未现代过》及相关研究 |
| 2000s—2022 | 在巴黎政治学院等机构任教，转向生态政治 | 盖娅、陆地与新气候体制 |

拉图尔的生平不能只看作职位和著作的排列。更重要的是，他不断改变研究对象：从宗教和文本，到实验室和技术，再到现代性制度与地球政治。

## 2. 不同阶段，他在追问什么？

拉图尔并不是始终围绕一个固定的“总问题”展开研究。他的研究对象和聚焦点不断移动：从实验室，到技术和现代性，再到气候与地球政治。各阶段的问题不同，但都在追踪事实、技术和秩序如何形成、稳定并产生后果。

| 阶段 | 主要研究对象 | 当时最核心的问题 |
|---|---|---|
| 实验室研究 | 科学家、样本、仪器、记录和论文 | 科学事实如何在实验实践中形成并获得可信度？ |
| 行动者网络理论 | 人类、非人类、设备、文本和组织 | 不同参与者如何建立连接，并共同推动一个事实或项目？ |
| 现代性批判 | 自然／社会分类与混合体 | 为什么现代人一边制造自然—社会混合体，一边又坚持把两者分开？ |
| 生态政治 | 气候科学、盖娅、国家和公众 | 在人类无法脱离地球系统的条件下，政治应如何重新组织？ |

贯穿这些阶段的连续线索不是一个固定答案，而是一种持续的追问：事实、技术和秩序是通过哪些人类与非人类的关系形成的？

在最早的实验室研究中，这个问题表现为：

> 科学事实究竟是本来就在那里、等待被发现，还是在实验、记录、论文、同行和机构的连接中逐渐稳定下来？

### 拉图尔的基本回答

科学事实并非虚构，但它也不是脱离实践而自动成立的对象。它与自然对象发生关系，同时要经过具体的组装、记录、验证、传播和维护。

```text
材料与实验
→ 记录与图表
→ 论文与引用
→ 争论与机构
→ 稳定的事实
```

“制造”不是凭空捏造，而是指事实如何在一组人类与非人类的连接中获得稳定性。拉图尔由此改变了观察事实的方式：不只问它属于自然还是社会，还要追问哪些人、物、设备、文本、制度和环境让它稳定、可信并产生后果。

### 回答背后的基本思路

```text
进入具体现场
→ 不预先分开自然与社会
→ 跟随人、物、设备和文本的连接
→ 打开已经稳定的事实
→ 重新描述事实如何形成
```

这也解释了拉图尔为什么会从实验室研究走向现代性批判，再走向生态政治：研究对象在变化，问题的连续线索仍然是事实、技术和秩序如何被共同组装。

### 必须保留的边界

拉图尔的回答不等于“科学事实都是假的”，也不等于“所有行动者拥有相同的权力”。关于行动者网络、转译、黑箱、纯化／杂合以及相关争议，留待后续详细展开。

## 3. 思想坐标：他从哪里来，与谁同行、争论？

### 思想资源与合作网络

拉图尔不适合用单线“师承”概括，更准确的是几组思想资源和合作关系：

| 关系 | 人物／传统 | 对拉图尔的意义 |
|---|---|---|
| 思想资源 | 米歇尔·塞尔 | 科学、哲学与混杂世界之间的连接思路 |
| 思想资源 | 加布里埃尔·塔德 | 以关联和模仿取代“社会实体”的思路 |
| 方法资源 | 加芬克尔、格雷马斯 | 对行动过程、意义和关系的细密分析 |
| 学术背景 | 科学知识社会学、STS | 将科学知识作为实践和制度对象研究 |
| 合作关系 | 史蒂夫·伍尔加 | 《实验室生活》与实验室民族志 |
| 合作关系 | 米歇尔·卡龙、约翰·劳、玛德琳·阿克里奇 | 行动者网络理论及转译研究 |

### 主要对话对象

| 对话对象 | 拉图尔接住的问题 | 他的改写 |
|---|---|---|
| 涂尔干 | 社会秩序如何可能 | 不把社会当作独立实体，而追踪社会如何被组装 |
| 塔德 | 个体如何模仿、发明和连接 | 将关联过程扩展到非人类和技术对象 |
| 强纲领／David Bloor | 科学知识如何成为社会研究对象 | 反对只用社会利益解释知识，要求非人类进入分析 |
| 马克思主义与批判社会学 | 权力、资本和支配如何组织社会 | 反对预先设定结构，强调具体网络的形成过程 |
| 生态思想与盖娅研究 | 人类如何处在地球系统中 | 将科学技术研究推进到气候政治 |

### 主要反对与批评

- **David Bloor**：认为 ANT 的广义对称会削弱社会学对知识和社会利益的解释；
- **John Searle**：担心“事实被建构”混淆事实的认识过程与事实本身的实在性；
- **马克思主义和批判社会学者**：认为网络分析可能弱化阶级、资本和结构性权力；
- **女性主义、后殖民和原住民研究者**：提醒“对称性”不能遮蔽性别、殖民、种族和环境不平等；
- **ANT 内部的修正者**：继承其方法，但补充权力、基础设施、身体、地方知识和政治责任。

### 如何评价他的位置

拉图尔的重要贡献，是把事实、技术和制度的形成过程变成可观察对象，并把人类与非人类共同纳入分析。与此同时，他的理论不能单独承担结构性权力、正义判断、长期历史因果和主体经验的解释任务。

因此，对拉图尔较准确的评价是：

> 他重新规定了我们观察事实和秩序生成的方式，但不是一套可以替代所有社会理论的完整解释体系。

## 4. 这套视角能看见什么：聚焦点、适用范围与局限

### 聚焦点：不同阶段分别看什么

拉图尔的聚焦点随着研究阶段变化：

| 阶段 | 聚焦点 |
|---|---|
| 实验室研究 | 科学主张如何在实验、记录、论文和引用中获得稳定性 |
| 行动者网络理论 | 人、物、设备、文本和组织如何建立连接并推动行动 |
| 现代性批判 | 自然／社会分类如何与现实中的混合体同时存在 |
| 生态政治 | 自然过程如何进入政策、公共争论和政治决策 |

这些聚焦点的连续性在于：他始终关注正在形成、尚未稳定、需要多方协作才能成立的事实、技术和秩序。

### 适用范围：他的理论适合解释什么

| 领域 | 能看清什么 |
|---|---|
| 科学知识 | 实验、仪器、论文、同行和机构如何共同稳定事实 |
| 技术与工程 | 装置如何改变行动路径，项目为何成功或失败 |
| 基础设施与组织 | 看似背景性的设备、标准、数据库和流程如何组织行动 |
| 科学争议 | 事实如何在证据、引用和联盟中获得权威 |
| 环境与气候政治 | 自然过程如何进入制度、经济和公共生活 |

它最适合解释具体的、中观尺度的动态过程：一组连接如何形成、扩张、断裂和重新组合。

### 局限：哪些问题需要其他理论补充

- 它能描述权力如何在网络中形成，但对阶级、资本、殖民、性别和种族等结构性不平等的解释不够充分；
- 它能说明秩序如何形成，却不能自动回答这个秩序是否正义、谁应承担责任；
- 它擅长追踪具体过程，单独解释长时段历史、国家体系和资本主义结构时会受限；
- 方法上的“对称”不等于现实中的平等，否则会遮蔽谁能发言、谁承担风险、谁拥有资源；
- “网络”必须建立在具体材料和连接证据上，不能变成解释一切的万能词。

因此，拉图尔的理论可以先用来回答：

> 一个事实、技术或秩序，是如何被一组人类与非人类的连接共同组装出来的？

当问题转向正义、结构性权力、长期历史因果或主体经验时，还需要结合马克思主义、女性主义、后殖民理论、政治哲学和心理社会理论。
