# 拉图尔页面：分层分批学习设计

> 状态：页面设计稿，尚未写入 `latour.html`。
>
> 设计目标：在边学习、边研究、边 coding 的过程中，把一个“完全不了解拉图尔”的人的理解过程完整记录下来；之后再从中提炼面向读者的展示版本。
>
> 核心原则：页面首先是研究工作台，其次才是面向读者的学习页面。每一层都可以详细展开，暂时不以快速、简洁或一次完成为目标。

## 当前工作方式：研究工作台，而不是成品展示页

这个项目采用“边学习、边 coding”的方式，因此页面设计要允许内容逐渐长出来：

- 可以先写很长的材料、疑问和暂时判断；
- 可以同时保留原著命题、二手解释、个人推测和待核对内容；
- 可以把未完成的争议和不确定性直接显示出来；
- 可以先实现一个阶段，再继续补下一个阶段；
- 不需要为了“给用户看”而过早压缩内容。

### 每个部分都允许详细呈现

一个完整的学习层可以包括：

1. 这一层要解决的学习问题；
2. 为什么这个问题重要；
3. 读者已有的直觉和常见误解；
4. 智者实际观察的对象和材料；
5. 从材料到判断的知识动作；
6. 概念如何从这个问题中长出来；
7. 原著段落、二手解释和资料链接；
8. 当前仍未解决的疑问；
9. 读者可以继续追踪的下一条路径。

这些内容不必全部显示在首屏，可以通过标题、锚点、折叠区和侧边目录组织，但不能因为追求页面简洁而提前删掉。

### 页面当前版本的完成标准

当前阶段不是“让陌生读者三分钟看懂”，而是：

> 我在继续理解拉图尔的过程中，能把自己的问题、证据、判断和不确定性准确放回页面对应的层级。

面向公众的简化版、摘要版和视觉优化版，等研究材料积累到一定程度后再另行制作。

## Markdown 标题与未来 HTML 层级的对应关系

本文件的标题不是普通文档目录，而是未来网页的信息架构。制作 HTML 时，原则上不重新拆分结构，直接将标题层级转换为页面层级：

| Markdown 层级 | HTML 页面层级 | 页面作用 | 默认状态 |
|---|---|---|---|
| `#` | 页面标题 / `<h1>` | 定义智者与整页学习任务 | 始终显示 |
| `##` | 学习阶段 / `<section>` + `<h2>` | 第一层到第五层的进入路径 | 研究版可全部展开，展示版再决定默认折叠 |
| `###` | 阶段内模块 / `<article>` + `<h3>` | 一个问题、案例、概念或阅读任务 | 随所在阶段显示 |
| `####` | 展开细节 / `<details>` + `<summary>` 或 `<h4>` | 来源、边界、例子、误读、练习 | 默认收起 |
| 普通段落 | 正文说明 / `<p>` | 解释当前标题要解决的学习问题 | 按层级显示 |
| 表格 | 对照卡 / `<table>` 或卡片组 | 比较概念、阶段、作品和争议 | 按上下文显示 |
| 引用块 | 关键问题 / `<blockquote>` | 提供读者需要带走的追问 | 视觉强调 |
| 代码块 | 路径图 / `<pre>` 或流程图 | 展示思想动作或阅读推进序列 | 视觉强调 |

### 转换约束

1. `##` 不用于普通知识分类，只用于“读者现在进入哪一层”。
2. `###` 的标题必须能回答“这一层具体要学什么”。
3. `####` 里的内容可以很详细；研究版可直接展开，展示版再决定是否折叠。
4. 每个 `##` 末尾应有一个“进入下一层前，读者需要会什么”的判断。
5. 如果一个 Markdown 标题无法对应明确的学习动作，说明内容还没有准备好进入 HTML。

### 未来 HTML 的骨架示意

```html
<main>
  <h1>拉图尔：如何重新看见自然、技术与社会</h1>

  <section data-layer="1">
    <h2>第一层：先知道他在挑战什么</h2>
    <article>
      <h3>首屏问题</h3>
      <p>...</p>
      <details>
        <summary>来源与边界</summary>
        <p>...</p>
      </details>
    </article>
  </section>

  <section data-layer="2" hidden>
    <h2>第二层：先看一个案例</h2>
    <article><h3>实验室如何产生事实</h3></article>
  </section>
</main>
```

因此，后续 HTML 设计应围绕 `data-layer`、展开／收起和学习进度展开，而不是重新做成平铺式的知识卡片。

## 入口层设计逻辑：建立认识必要性

这一层不是人物评价，也不是页面标题文案，而是决定首屏材料选择的内部设计逻辑：需要让读者从一个现实问题进入拉图尔的观察方式。

它不应依赖名人简介、影响力排名或概念清单，而应促成一次认识上的转折：

```text
我遇到一个现实问题
→ 习惯解释无法说明它为什么复杂
→ 拉图尔改变了我观察问题的单位
→ 我获得一种可以自己使用的追踪方法
→ 我愿意继续进入他的案例、概念和著作
```

### 1. 从读者已经遇到的混合问题开始

拉图尔最适合从那些无法只归入“自然”或“社会”的问题开始：

- 疫苗既是生物医学对象，也是信任、政策、供应链和舆论对象；
- 人工智能既是算法，也是数据、平台、劳动者、法律和基础设施；
- 全球变暖既是物理过程，也是产业、国家、科学报告和政治冲突；
- 一扇自动门既是物理装置，也是对人的行动要求。

页面先让读者回答：

> 这些问题如果只交给自然科学解释，或只交给社会科学解释，会遗漏什么？

### 2. 展示旧解释为什么不够

不要马上说拉图尔“提出了 ANT”，而是做一个三栏对照：

| 常见解释 | 它能看到什么 | 它容易遗漏什么 |
|---|---|---|
| 纯自然解释 | 物质、机制、因果 | 设备、组织、政策和信任如何让事实产生作用 |
| 纯社会解释 | 利益、权力、身份 | 微生物、技术装置、材料和环境如何改变行动路径 |
| 拉图尔的追踪 | 人类与非人类如何连接并共同改变事态 | 需要持续跟随具体过程，不能凭空宣布“万物皆网络” |

这一步不是为了证明拉图尔永远正确，而是让读者知道：他的理论是针对哪一个解释缺口出现的。

### 3. 说明他带来的不是一个结论，而是一种观察能力

拉图尔值得认识，主要因为他把读者的提问方式改成了四个动作：

1. 不先把自然和社会分开；
2. 跟着正在行动的人、物、文本、设备和机构走；
3. 打开已经稳定的事实或技术的“黑箱”；
4. 观察连接如何被转译、争议和重新组装。

页面可以把这四个动作写成“你学会之后能做什么”，而不是“拉图尔的四个理论”：

- 看一项政策时，能发现它依赖哪些技术和材料；
- 看一项科学结论时，能追踪它如何获得可引用性和权威；
- 看一个失败项目时，能发现哪些连接没有稳定下来；
- 看生态危机时，能意识到自然事实已经进入政治和制度。

### 4. 回答“为什么是现在”

拉图尔值得被重新认识，是因为今天的现实越来越具有“杂合”特征：平台技术同时改变经济、劳动和身份；气候变化把科学、政治和日常生活绑在一起；医疗技术把身体、数据、伦理和国家治理连接起来；AI 系统让算法、基础设施、企业规则和人的判断共同参与决策。

页面应明确：拉图尔不直接提供这些问题的现成答案，但他提供了一种不把问题过早拆开的观察方式。

### 5. 同时说明“不必把他当作什么人”

“值得认识”必须和边界一起出现，否则会变成思想崇拜。第一层应同时写出：

- 他不是在说科学事实都是假的；
- 他不是在说人和非人类拥有完全相同的意图；
- 他不是用“网络”解释一切；
- 他的对称性方法可能弱化结构性权力、性别和不平等，需要和其他理论对话。

### 6. 第一层的最终出口

这一层的阶段性验收标准不是记住 ANT 的定义，而是读者能够回答：

> 拉图尔帮助我们观察那些既是自然、技术、制度又是政治的问题，并追踪这些不同参与者如何共同把一个事实、装置或秩序组装出来。

然后页面给出两个入口：

- **想看他如何观察？** 进入“实验室案例”；
- **想先了解他反对什么？** 进入“自然／社会二分的困境”。

## 最小全局：学习拉图尔的第一张地图

在进入实验室案例或 ANT 概念之前，页面应先给出一个“最小全局”。它不是百科全书，而是一张能让读者知道后面内容如何归位的地图。

### 最小全局必须回答的六个问题

#### 1. 他是谁

布鲁诺·拉图尔（Bruno Latour，1947—2022），法国思想家、科学技术研究者和哲学社会学家。他的重要性不只在于提出了“行动者网络理论”，还在于他把实验室、技术、科学事实、现代性和生态政治放进了一条连续的研究路径中。

#### 2. 他面对的总问题是什么

> 我们为什么总把自然和社会分成两个世界，而现实中的科学、技术、政治和生态问题却不断把它们重新混在一起？

#### 3. 他观察什么材料

他不是从抽象的“社会”出发，而是进入具体现场：

- 实验室里的科学家、样本、仪器和论文；
- 技术项目中的工程师、设备、设计方案和失败过程；
- 科学争议中的报告、引用、经费和制度；
- 气候政治中的科学事实、国家、公众和非人类环境。

#### 4. 他反复使用什么知识动作

```text
进入现场
→ 跟随行动者
→ 打开黑箱
→ 追踪转译
→ 观察人类与非人类如何共同组装事实与秩序
```

这比直接说“拉图尔的认知方式是田野调查”更准确，因为它展示了田野材料如何被转化为理论判断。

#### 5. 核心概念如何连成一条线

```text
实验室民族志
→ 铭写装置
→ 行动者与网络
→ 转译与黑箱
→ 杂合／纯化
→ 现代性批判
→ 关切、盖娅与陆地政治
```

这条线不是严格的思想阶段年表，而是帮助读者理解：后来的概念如何从早期观察问题中长出来。

#### 6. 应该先读什么，之后读什么

| 阅读阶段 | 先读什么 | 想获得什么 |
|---|---|---|
| 进入现场 | 《实验室生活》 | 看拉图尔如何描述科学工作 |
| 学会跟随 | 《科学在行动》 | 理解追踪、黑箱和铭写 |
| 看到现代性问题 | 《我们从未现代过》 | 理解纯化与杂合 |
| 系统化方法 | 《重组社会》 | 进入 ANT 的理论表述 |
| 进入晚期 | 《面对盖娅》《着陆何处》 | 看网络分析如何转向生态政治 |

### 最小全局的页面呈现方式

最小全局可以设计成一个完整但不拥挤的“总览区”，包含：

1. 一句话定位；
2. 一个总问题；
3. 一条思想推进线；
4. 一个知识动作流程；
5. 一张核心概念关系图；
6. 一条阅读顺序。

每一项都可以继续展开到详细内容，但读者先用几分钟获得整体认知，再决定从哪个部分深入。

### 最小全局的完成标准

读者看完这一层后，不要求会解释“转译”或“广义对称性”，但应该能够用自己的话说出：

> 拉图尔从科学和技术的具体现场出发，追踪人类与非人类如何形成连接，借此质疑自然／社会的先验分离，并把这套观察方式推进到现代性和生态政治问题。

如果读者能够说出这句话，后面的详细阅读就不再是零散名词，而是对一张已有地图的逐步放大。

## 一、先改变页面任务

### 人物生平的展开接口

最小全局的第一部分只呈现生平轮廓，不在这里展开完整传记。详细生平可以从以下角度分别建立内容模块：

### 1. 时间线

- 出生与家庭背景；
- 哲学、神学和人类学训练；
- 科特迪瓦经历；
- 索尔克研究所实验室研究；
- 巴黎高等矿业学校与巴黎政治学院任教；
- 霍尔贝格奖、京都奖及晚年工作。

### 2. 学术训练与知识资源

- 哲学与神学训练如何影响他对真理、信仰和解释的敏感度；
- 人类学如何影响他进入实验室和技术现场；
- 科学技术研究如何成为他的主要学术位置。

### 3. 研究对象的转向

```text
宗教文本
→ 实验室
→ 技术项目
→ 现代性制度
→ 气候、盖娅与地球政治
```

每一次转向都需要回答：

- 原来的研究对象留下了什么问题；
- 新对象为什么成为必要；
- 旧的观察方法保留了什么；
- 哪些概念因此被改写。

### 4. 合作者与学术网络

- 史蒂夫·伍尔加：《实验室生活》及实验室民族志；
- 米歇尔·卡龙：行动者网络理论的共同发展；
- 约翰·劳：科学技术研究与网络分析；
- 塔德：拉图尔重新发现的思想资源；
- 涂尔干、科学知识社会学和现代性理论：拉图尔持续回应的传统。

这里要区分共同研究、学术交往、思想资源和后世解释，不能把所有关系都写成师承。

### 5. 著作与人生阶段的对应

每本重要著作都应说明：它处于拉图尔人生的哪个阶段，回应什么问题，改变了什么研究方向。

### 6. 时代背景

- 1970—1980 年代科学知识社会学和科学技术研究的兴起；
- 科学大战及自然科学与人文学科的争论；
- 全球化、技术治理和生态危机的加剧；
- 气候变化如何推动拉图尔晚期转向政治和地球问题。

### 7. 资料类型

- 拉图尔本人的自述、访谈和演讲；
- 传记、讣告和学术机构资料；
- 合作者回忆和学术通信；
- 原著出版信息和版本资料；
- 后世研究者对其思想阶段的重构。

人物生平模块的目标不是补齐所有个人细节，而是解释：哪些人生经历和学术位置，使拉图尔形成了从现场、关系和非人类行动出发的观察方式。

拉图尔页面不先回答“拉图尔有哪些概念”，而先回答四个新手问题：

1. 进入他的研究之前，需要建立什么认识必要性？
2. 他究竟在观察什么？
3. 他和普通社会学的看法有什么不同？
4. 我应该先读哪一本，读到哪里，再进入下一层？

因此，页面的基本单位不是“概念卡”，而是“学习层级”。每一层只解决一个进入障碍，并给出进入下一层的理由。

## 二、五层学习路径

```text
第一层：先知道他在挑战什么
    ↓
第二层：通过一个具体案例看他怎么观察
    ↓
第三层：从观察动作中提炼概念
    ↓
第四层：看这些概念如何组成理论和著作路径
    ↓
第五层：理解争议、晚期转向与自己的判断
```

页面在研究版中可以全部展开。层级的作用不是限制内容，而是让大量内容有清晰的位置；如果需要模拟新手阅读路径，再用折叠或“继续进入”控制阅读节奏。

---

## 三、第一层：先知道拉图尔在挑战什么

### 学习目标

读者暂时不需要知道 ANT、转译、广义对称性等术语，只需要理解一个冲突：

> 我们总把自然和社会分成两个世界，但现实中的许多问题根本无法只归入其中一个世界。

### 页面内容

#### 首屏问题

> 当一项“科学事实”出现时，究竟是谁让它变得稳定、可信并产生政治后果？

下方只放三个例子：

- 实验室里的微生物；
- 一扇会自动关闭的门；
- 全球变暖或臭氧空洞。

三个例子共同指向：人、设备、材料、制度、文本和自然过程总是一起起作用。

### 这一层不放什么

- 不先解释“行动者网络理论”；
- 不先放完整生平；
- 不先列全部著作；
- 不把他简单写成“科学是社会建构的”理论家。

### 离开这一层时，读者应能回答

> 拉图尔试图拆开的，不是“科学对不科学”，而是“自然与社会是否可以先被分开再解释”。

### 资料状态

- [二手导读] `card-拉图尔结构阅读底稿.md` 的“核心问题”；
- [待核原著]《我们从未现代过》开篇关于“纯化／杂合”的论证；
- [网络补充] 拉图尔个人资料、SEP/百科条目及相关公开访谈。

---

## 四、第二层：先看一个案例，而不是先背理论

### 学习目标

让读者看到拉图尔的观察动作，而不是记住他的定义。

### 主案例：实验室如何产生“事实”

页面用一个纵向故事展开：

```text
样本与仪器
→ 读数与图表
→ 实验记录与论文
→ 同行争论与引用
→ 经费、机构与传播
→ 一个可以被进一步使用的科学事实
```

关键不是说“事实是假的”，而是让读者看到：事实要成为稳定事实，需要一整套人类和非人类的连接。

### 可选第二案例：阿拉米斯或门闩

当读者完成实验室案例后，再用技术案例展示：

- 技术不是工程师意图的直接实现；
- 装置会把行动要求转交给人；
- 失败的项目同样能揭示网络如何断裂。

### 页面交互

采用“点击追踪”而不是长篇解释：

- 点击“微生物”：看到它如何改变实验结论；
- 点击“仪器”：看到它如何把材料变成可比较的记录；
- 点击“论文”：看到事实如何获得可移动性；
- 点击“机构”：看到事实如何获得资源和持续性。

### 读者应学会的动作

不要问：

> 这个事实到底是自然的，还是社会的？

先问：

> 哪些行动者让它成为一个可以被引用、传播和继续使用的事实？

### 资料状态

- [原著待核]《实验室生活》；
- [二手整理] 当前拉图尔结构底稿中的“跟随、打开黑箱、铭写装置”；
- [暂不写成定论] “科学事实是被建构的”需要避免简化为“科学事实是虚假的”。

---

## 五、第三层：从观察动作提炼概念

只有完成案例后，才出现概念。概念按照“它解决什么观察难题”排列，而不是按术语表排列。

| 观察难题 | 概念 | 页面解释重点 |
|---|---|---|
| 谁在改变事态？ | 行动者 | 不预先限定只有人能行动；行动者是能让事情发生变化的实体。 |
| 连接如何形成？ | 网络 | 不是社交关系图，而是追踪行动连接后的描述结果。 |
| 连接如何改变彼此？ | 转译 | 不是原封不动传播，而是每次传递都会重新定义利益与目标。 |
| 稳定事实如何被封装？ | 黑箱 | 一个看似单一的事实或技术，内部其实由许多连接维持。 |
| 为什么自然与社会总是纠缠？ | 杂合／纯化 | 制度一边制造混合体，一边用分类把它们拆开。 |
| 科学如何把远方带到眼前？ | 不变的可动者 | 地图、图表、标本和记录让对象可以移动、比较、叠合。 |

### 这一层的阅读提示

每个概念卡必须包括五栏：

1. 它要处理的观察难题；
2. 拉图尔实际看到了什么；
3. 这个概念改变了哪一种传统解释；
4. 它最容易被误读成什么；
5. 读者可以用什么现实案例练习。

### 不采用的呈现方式

不做“行动者网络理论、转译、广义对称性、黑箱……”的平铺词典。那会让新手知道名词，却不知道为什么需要这些名词。

## 六、第四层：概念如何组成著作和思想阶段

### 学习目标

让读者理解拉图尔不是一直在重复 ANT，而是在不断把同一套观察方式推向新的对象。

### 作品路径

```text
《实验室生活》
看科学事实如何在现场形成
        ↓
《科学在行动》
提炼跟随、争议、黑箱与铭写的方法
        ↓
《我们从未现代过》
把实验室观察扩展到现代性分类
        ↓
《重组社会》
系统说明 ANT 的分析承诺
        ↓
《面对盖娅》《着陆何处》
把网络与杂合问题推进到生态政治
```

### 页面显示方式

每本书只显示三个信息：

- 这本书解决前一本书留下的什么问题；
- 读者应重点观察什么；
- 读完后可以进入哪一层。

书目详情、版本信息和链接放入可展开的“资料柜”，不占据主阅读流。

## 七、第五层：争议与晚期转向

这一层不作为新手入口，而作为读者已经掌握基本观察方法后的反思区。

### 必须呈现的三组争议

1. **建构论争议**：事实被建构，是否意味着事实不真实？
2. **对称性争议**：把人和非人类同时纳入分析，是否会遮蔽权力、性别和不平等？
3. **批判转向**：从“事实”到“关切”，是理论修正，还是表达方式变化？

### 晚期生态转向的页面位置

不把“盖娅”“陆地”提前塞进 ANT 入门，而是在最后设置一个转向问题：

> 当研究对象从实验室和技术项目变成气候危机，拉图尔早期的观察方法还能解释什么？

这样读者能看出晚期思想不是凭空换题，而是把“人类—非人类—制度网络”的分析推进到地球政治。

---

## 八、页面上的学习进度显示

页面顶部可设置一个轻量进度条：

```text
已完成 0/5 层：认识问题 → 看案例 → 学概念 → 读著作 → 判断争议
```

每一层结束时显示一条“你现在可以继续”的判断，而不是测验分数：

- 如果你能说出自然／社会二分为什么不够，可以进入案例；
- 如果你能追踪实验室中的人、设备、文本和机构，可以进入概念；
- 如果你能解释“转译”不是传播，可以进入著作路径；
- 如果你能区分早期 ANT 与晚期生态政治，可以进入争议。

## 九、拉图尔页面的认知方式如何呈现

页面不直接把“田野调查”作为拉图尔的标签。更准确的表达是：

> 拉图尔从现场开始：他进入实验室、技术项目和生态争议，跟随行动者如何连接，在不预先区分自然与社会的情况下，追踪事实、技术和政治对象是怎样被组装出来的。

这里的“田野”只是资料来源和知识动作的一部分，不是页面标题。页面真正要展示的是：

```text
进入现场
→ 跟随行动者
→ 打开已稳定的黑箱
→ 追踪转译和连接
→ 重新描述自然／社会的混合现实
```

## 十、第一版页面暂不做什么

- 不把全部生平做成首屏时间线；
- 不一次展开所有著作；
- 不把 ANT 作为无背景的理论定义；
- 不把拉图尔写成“科学都是假的”；
- 不把晚期盖娅政治和早期实验室研究混成一个平面；
- 不把批评者名单当成理论争议本身；
- 不在资料未核对时写未经证实的师承关系。

---

## 十一、实现顺序

1. 先把本设计稿确认成页面信息架构；
2. 再从拉图尔资料底稿中抽取第一层和第二层的正文；
3. 先实现“完整内容可展开”的研究版页面原型；
4. 用一个实验室案例测试读者是否能自然进入概念；
5. 再补第三至第五层；
6. 最后补精确原著引用和资料版本。

第一版页面的完成标准不是“资料最多”，而是：一个不了解拉图尔的读者打开页面后，能明确知道自己现在处于哪一层、下一步为什么值得继续。
